Comment activer un provider ?
Google
  1. Aller dans Paramètres → Comptes mail
  2. Ajouter ou modifier un compte → type Google OAuth2 (Gmail API)
  3. Renseigner le Client ID et le Client Secret obtenu depuis Google Cloud Console
  4. URL de callback à déclarer chez Google :
  5. Redémarrer l'application pour activer le bouton SSO
Microsoft / Azure AD
  1. Aller dans Paramètres → Comptes mail
  2. Ajouter ou modifier un compte → type Microsoft OAuth2 (Graph API)
  3. Renseigner le Client ID, Client Secret et le Tenant ID depuis Azure App Registrations
  4. URL de callback à déclarer :
  5. Redémarrer l'application pour activer le bouton SSO
Les Client ID et Client Secret sont chiffrés en base de données (AES-256). Le même compte mail sert à la fois pour la synchronisation des emails et pour le bouton de connexion SSO.
