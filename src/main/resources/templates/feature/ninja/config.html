Prochaines étapes après configuration :

  • Lier chaque client à son organisation NinjaOne (fiche client)
  • Synchroniser les appareils → alimenter les abonnements PER_DEVICE
  • Générer les liens d'installation par organisation
  • Afficher l'état des appareils dans le portail client

Comment créer les credentials NinjaOne :

  1. Connectez-vous à NinjaOne → Administration
  2. Apps & API → API → Add application
  3. Type : Client Credentials
  4. Scopes : monitoring, management, control
  5. Copiez le client_id et client_secret
