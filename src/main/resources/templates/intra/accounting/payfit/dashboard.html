Importer un fichier FEC
Format FEC (Fichier des Écritures Comptables) — fichier texte pipe-délimité (.txt ou .fec) produit par Payfit, Silae, ADP, Sage Paie, etc. L'import est idempotent : les écritures déjà importées sont ignorées.
Formats acceptés : .txt, .fec, .csv

  • Dates au format AAAAMMJJ (ex : 20260131)
  • Montants avec virgule décimale (ex : 15000,00)
  • Encodage UTF-8 (ou ISO-8859-1 pour les anciens exports)
Exporter en FEC
Générez le FEC de votre exercice comptable. Ce fichier est obligatoire en cas de contrôle fiscal DGFiP (art. L. 47 A du LPF). Il contient toutes les écritures de l'exercice.
Le fichier généré est encodé en UTF-8. Renommez-le au format SIREN_FEC_AAAAMMJJ.txt avant de le remettre à l'administration fiscale.
Connexion API Payfit Phase 5

L'API Payfit permettra de récupérer automatiquement les journaux de paie sans export manuel. Cette fonctionnalité sera disponible dans une prochaine version. En attendant, exportez le journal de paie depuis Payfit et importez-le ci-dessus.

  1. 1 Connectez-vous à votre espace Payfit
  2. 2 Allez dans Paramètres → Exports comptables
  3. 3 Choisissez "Export FEC" pour la période souhaitée
  4. 4 Téléchargez le fichier .txt
  5. 5 Importez-le via le formulaire "Importer un fichier FEC" ci-dessus
