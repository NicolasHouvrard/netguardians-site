Synchronisation Stripe

Importe depuis l'API Stripe les PaymentIntents réussis, les virements vers la banque (Payouts) et les remboursements (Charges refunded) sur la période choisie. Chaque transaction est dédupliquée par son identifiant Stripe.

Webhook Stripe

Configurez ce webhook dans votre tableau de bord Stripe pour que les événements soient traités automatiquement en temps réel.

Événements à écouter :

  • payment_intent.succeeded
  • payout.paid
  • charge.refunded
