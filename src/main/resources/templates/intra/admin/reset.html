Attention — action irréversible

Cette action supprime définitivement et sans retour possible toutes les données métier. Faites un dump PostgreSQL avant de continuer.

Sera supprimé
  • Clients & contacts
  • Commandes & factures
  • Produits & catégories
  • Abonnements & plans
  • Tickets & interventions
  • Comptabilité complète
  • Boutique en ligne
  • Stock
  • Fournisseurs & syncs
  • Messagerie & campagnes
  • Équipes
  • Comptes portail clients
Sera conservé
  • Pages du site public (pages, blocs, menus)
  • Paramètres du site
  • Modules de navigation intra
  • Tenants & rôles
  • Comptes utilisateurs intra (admin, commercial, tech…)
  • Taux de TVA

Backup recommandé avant toute action

Exécuter sur le serveur ou via tunnel SSH :

pg_dump \
  -h localhost \
  -U UTILISATEUR \
  NOMBASE \
  > backup-$(date +%Y%m%d-%H%M%S).sql

Ou depuis le script SQL fourni (pour psql manuel) : 

psql -h HOST -U USER \
  -d DATABASE \
  -f reset-prod-data.sql
