Configurez les boîtes mail pour la réception et l'envoi automatique
Google / Gmail : créez un projet sur Google Cloud Console, activez Gmail API + Calendar API, créez des identifiants OAuth2 (Client ID + Secret), ajoutez le redirect URI http://localhost:8080/intra/mail/oauth/google/callback.
Microsoft / Outlook : enregistrez une app sur Azure Portal, ajoutez les permissions Mail + Calendars, copiez le Client ID et le Secret, redirect URI : http://localhost:8080/intra/mail/oauth/microsoft/callback.
Autre serveur : activez IMAP et utilisez un App Password si la double authentification est activée.
